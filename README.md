# Задание 2. Автотесты для API

# Проект автоматизации тестирования API сайта [https://stellarburgers.nomoreparties.site/](https://stellarburgers.education-services.ru/)

- **Создание пользователя:**
  - создать уникального пользователя;
  - создать пользователя, который уже зарегистрирован;
  - создать пользователя и не заполнить одно из обязательных полей.

- **Логин пользователя:**
  - вход под существующим пользователем;
  - вход с неверным логином и паролем.

- **Создание заказа:**
  - с авторизацией;
  - без авторизации;
  - с ингредиентами;
  - без ингредиентов;
  - с неверным хешем ингредиентов.
 
**Запуск всех тестов**
>  pytest -vv

**Команда запуска автотестов с Allure**
> pytest --alluredir=allure_report

**Команда для получения Allure отчета**
> allure serve allure_report

**Установка зависимостей**

> `$ pip install -r requirements.txt`
